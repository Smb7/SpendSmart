## Overview

SpendSmart is a modern web application designed to help users track their spending habits and develop healthier financial behaviors. The app provides an intuitive interface for managing expenses, gaining insights into spending patterns, and taking control of personal finances.

### 1. **Overview Dashboard**

## 💡 How It Works

SpendSmart simplifies personal finance management with three core functions accessible from the main dashboard:

1. **View all transactions** - Browse your complete expense history at a glance
2. **Add new expenses** - Quickly log spending with a streamlined form
3. **Manage entries** - Edit or delete transactions as needed
